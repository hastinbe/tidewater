Tidewater

A from-scratch reimplementation of the Warcraft II: Battle.net Edition engine, written in Rust. It runs on your own copy of the game.

Download the latest release

    You need the game files

    Tidewater contains no game data. Bring your own copy of Warcraft II: Battle.net Edition (for example the GOG release). The first time you start it, an import screen finds an install, or you can choose:

    • a GOG installer or an installed game folder,
    • a CD or a CD image (.iso, .bin/.cue, .mdf, .nrg),
    • any folder that holds the game's .mpq files.

    The files are copied once into Tidewater's own data folder. Your installation is never changed. The 1995 DOS edition is not supported.

    What works today

    • Both campaigns: all 52 missions of Tides of Darkness and Beyond the Dark Portal, with briefings, score screens, endings and credits.
    • Custom games on any map, with the original setup choices, and computer players that build, train, attack and cast.
    • Saved games, sound, music and video from your own files.
    • Early multiplayer: Local Network and Direct IP games.
    • Faithful rules: the simulation is deterministic and checked against recordings of the original game.
    • Optional improvements, all off by default.
    • Desktop: Windows, macOS and Linux. iPhone and Android builds are early.

    Install

    • Windows: run the setup.exe. It installs for your user only and needs no administrator.
    • macOS: open the disk image and drag Tidewater to Applications. The app is not signed, so the first time, right-click it and choose Open, then confirm. After that it opens normally.
    • Linux: unpack the .tar.gz and run tidewater.

    Tidewater checks for newer releases when it starts and offers to update. Turn that off with update_check=0 in settings.txt or the --no-update-check flag.
